A world-class, ultra-premium web application perfectly designed for **Maa Kali Mistanno Bhandar**, a renowned Bengali sweet shop in Purbba Radhanagar. This beautifully engineered digital storefront highlights authentic Bengali confectionary, curated wedding specials (Biye Barir Totto), and traditional regional staples using cutting-edge e-commerce UI design. 

This project was carefully designed and built by **Suvadip Panja**.

--

## 🌟 Spectacular Features
- **Ultra-Premium UI/UX:** A pristine, clean, app-like white/cream luxury layout optimized for food presentation.
- **Asymmetric Menu Collections:** Beautifully drop-shadowed product cards featuring dynamic visual representations of hot Rosogolla, Sandesh platters, Jalebis, and Khaja.
- **Cinematic Visual Tour:** A fully interactive, incredibly smooth 3D Swiper.js image carousel showcasing high-end sweets.
- **Authentic Google Reviews:** Integrated original 5-star customer testimonials with beautiful avatar UI elements.
- **State-of-the-Art Animations:** Implemented complex scroll-reveal interactions utilizing the Intersection Observer API.
- **Fully Responsive Structure:** Mobile-first engineering ensures the site looks magnificent on desktop, tablet, and smartphone browsers.

--

## 🛠️ Technology Stack
- **Framework:** [Vite](https://vitejs.dev/) - Blazing fast frontend build tool.
- **Core Languages:** Semantic HTML5, Vanilla JavaScript (ES6+), Advanced Custom CSS3.
- **Libraries & Assets:**
  - [SwiperJS](https://swiperjs.com/) for hyper-smooth coverflow 3D galleries.
  - [Phosphor Icons](https://phosphoricons.com/) for beautifully crisp UI iconography.
  - Luxury Web Typography (`Outfit` & `Playfair Display`) delivered via Google Fonts.

## 🚀 Getting Started

If you wish to run this repository locally without making changes:

### Prerequisites:
Ensure you have [Node.js](https://nodejs.org/) installed.

### Installation:
1. Clone the repository:
   ```bash
   git clone https://github.com/SuvadipPanja/kalimata_sweets.git
   ```
2. Navigate to the project directory:
   ```bash
   cd kalimata_sweets
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Execution:
To spin up the blazing-fast Vite local development server:
```bash
npm start
```
